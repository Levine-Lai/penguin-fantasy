# 企鹅杯管理后台

入口：https://penguin-fantasy.pages.dev/admin/

管理员密码在本机 `.private/admin-access.txt`。不要把这个文件上传到 GitHub 或发给玩家。

## 决斗开始前

1. 玩家登录自己的 FPL ID，无需验证口令。
2. 玩家进入 https://penguin-fantasy.pages.dev/arena/ 直接报名；首页第二阶段沿用已登录账号。
3. 当前测试阶段已开放 GW9；GW9 DDL 前的提交归属 GW9，无需再手动开放。
4. DDL 到达后服务器自动拒绝新增提交；下一轮需要管理员选择新比赛周并开放。

## 决斗管理

- 记录显示发起人、对手、FPL ID、服务器提交时间（北京时间）、比赛周、状态和结果。
- 每轮最多5组，按数据库提交顺序接受，同轮双方不得参与另一组。
- 每位玩家当轮只能提交一条有效记录，不可自行修改或撤销；管理员移除后允许重新选择对手并提交。报名身份与右上角登录一致，不需要再次登录。
- DDL 前玩家只看到报名窗口及本人已报名确认，不显示人数、本人对阵或其他报名情况；DDL 后统一显示当轮对阵，后台不受此限制。
- GW9–GW20 每人5次主动挑战权；被挑战不扣主动次数；平局返还。
- “移除”会从玩家端删除有效对阵并释放该记录占用的名额和主动次数；若已经结算，其血量影响也从派生结果中排除。原记录与原因保留在后台。
- 每日07:30，仅对该GW全部比赛结束且队长快照齐全的记录结算一次。胜负±1血，平局0血。副队长兜底计分沿用FPL快照，原队长选择率不变。
- `/test/` 继续是演示，与正式记录隔离。

## 公告

选择北京时间日期，填写标题和内容。当天访问首页、规则或正式决斗页的玩家会看到公告；已经打开的页面在恢复前台且距上次读取超过5分钟时检查。支持撤下，记录保留。

## 登录玩家

- 只记录玩家在右上角明确完成的登录，显示玩家名称、FPL ID、首次/最近登录时间和登录设备；页面浏览、恢复已登录状态及退出不计入。
- 登录按玩家填写的 FPL ID 识别，不验证官方 FPL 账号归属；决斗报名沿用该 ID，不需要额外口令。
- 新列表从此次更新起独立记录，保留90天，不保存原始IP；旧浏览/识别事件保留但不导入新登录列表，以免混入历史测试与重复识别。

## 运维

- 独立D1数据库：`penguin-fantasy-operations`；迁移：`npx wrangler d1 migrations apply penguin-fantasy-operations --remote --config cloudflare/fpl-proxy/wrangler.jsonc`。
- 首次配置：`node scripts/provision-operations.mjs`。脚本幂等复用本机私有凭据，将管理员密码哈希、会话签名密钥和代理密钥写入Cloudflare secrets。更换机器先安全转移私有凭据，勿重新运行覆盖既有密钥。
- 管理会话8小时；玩家登录会话12小时。所有管理接口都在服务端校验权限；密码不进入客户端、Cookie使用HttpOnly/Secure/SameSite。
- 普通FPL公开只读接口不变。运营接口只接受带代理密钥的Pages转发，客户端不能直连Worker绕过代理。
